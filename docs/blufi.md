# Настройка Wi-Fi через BluFi (совместно с `esp-wifi-connect`)

Этот документ описывает, как включить и использовать BluFi (настройка Wi-Fi через BLE) в прошивке XiaoZhi совместно со входящим в состав дерева исходников компонентом `esp-wifi-connect`, который обрабатывает подключение к Wi-Fi и хранение учётных данных. Подробности протокола см. в официальной [документации Espressif по BluFi](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/api-guides/ble/blufi.html).

## Предварительные требования

- Микросхема и конфигурация прошивки, поддерживающие BLE.
- В `idf.py menuconfig` включите `WiFi Configuration Method -> ESP-BluFi` (`CONFIG_USE_ESP_BLUFI_WIFI_PROVISIONING=y`). Если вы хотите использовать BluFi, отключите в этом же меню параметр Hotspot (точка доступа); в противном случае по умолчанию будет выбрана настройка через точку доступа.
- Сохраните инициализацию NVS и цикла событий по умолчанию, выполняемую в `app_main` проекта.
- Должен быть выбран ровно один из `CONFIG_BT_BLUEDROID_ENABLED` / `CONFIG_BT_NIMBLE_ENABLED`; они взаимоисключающие.

## Рабочий процесс

1. Телефон (с официальным приложением EspBlufi или другим клиентом BluFi) подключается к устройству по BLE и передаёт целевые SSID / пароль Wi-Fi. Телефон также может запросить через протокол BluFi список сетей Wi-Fi, обнаруженных устройством при сканировании.
2. При наступлении события `ESP_BLUFI_EVENT_REQ_CONNECT_TO_AP` устройство сохраняет учётные данные в `SsidManager` (сохранение в NVS выполняет компонент `esp-wifi-connect`).
3. Затем устройство запускает `WifiStation` для сканирования и подключения; прогресс сообщается обратно по BluFi.
4. Если настройка завершилась успешно, устройство автоматически подключается к новой сети Wi-Fi. При ошибке отправляется статус ошибки.

## Шаги

1. **Настройте**: включите `ESP-BluFi` в menuconfig, затем соберите и прошейте прошивку.
2. **Запустите настройку**: при первой загрузке без сохранённых учётных данных Wi-Fi устройство автоматически переходит в режим настройки.
3. **На стороне телефона**: откройте приложение EspBlufi (или другой клиент BluFi), выполните сканирование и подключение к устройству, при желании включите шифрование, затем введите SSID / пароль Wi-Fi и отправьте их.
4. **Понаблюдайте результат**:
   - Успех: BluFi сообщает об успехе, и устройство подключается к Wi-Fi.
   - Ошибка: BluFi сообщает об ошибке; повторите попытку или проверьте маршрутизатор.

## Примечания

- BluFi нельзя использовать одновременно с настройкой через точку доступа. Если настройка через точку доступа уже включена, устройство будет использовать её. Оставляйте в menuconfig только один способ настройки.
- При повторных тестах очищайте или перезаписывайте сохранённый SSID (пространство имён NVS `wifi`), чтобы устаревшие учётные данные не мешали следующему запуску.
- Если вы пишете собственный клиент BluFi, следуйте формату кадров протокола из официальной документации (ссылка выше).
- Ссылки на скачивание приложения EspBlufi приведены в официальной документации.
- Из-за изменений API BluFi в IDF 5.5.2 прошивки, собранные в 5.5.2, объявляют имя Bluetooth как `"Xiaozhi-Blufi"`, тогда как 5.5.1 использует `"BLUFI_DEVICE"`.
